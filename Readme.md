# Chest X-Ray Classification via VGG-Swin HybridNet

This repository contains the complete end-to-end pipeline developed for a Master's thesis focusing on medical image classification. It implements a custom serial dual-backbone neural network (`VGGSwinHybridNet`) to classify Chest X-Ray images into mutually exclusive pathological categories (e.g., Atelectasis, Cardiomegaly, Effusion, Normal).

## 🌟 Project Overview

The pipeline is designed to be highly rigorous, computationally efficient, and clinically interpretable. It encompasses:
1. **Data Preparation**: Merging NIH and CheXpert datasets and filtering for single-label exclusive pathologies.
2. **Preprocessing**: Extracting the Lung Region of Interest (ROI) using a Keras-based U-Net and enhancing contrast via CLAHE.
3. **Hyperparameter Optimization (HPO)**: Using Optuna and a lightweight proxy model to find optimal learning rates, weight decays, and MixUp ratios.
4. **Training**: A highly optimized PyTorch training pipeline featuring GroupShuffleSplit (patient-level leakage prevention), MixUp, Label Smoothing, Cosine Annealing, and Mixed Precision (AMP).
5. **Evaluation & Thresholding**: Computing robust test metrics and using Youden's J statistic to discover optimal per-class decision thresholds.
6. **Baselines**: Standardized Ablation studies against VGG16 and Swin-Small Transformer.
7. **Interpretability**: A custom Serial Grad-CAM implementation that extracts distinct heatmaps from both the CNN and Transformer backbones simultaneously.
8. **Deployment**: An interactive Streamlit web application for clinical demonstration.

## 📂 Repository Structure

### 1. Data Pipeline
- `config.py`: Global configuration for hyperparameters, dataset paths, target classes, and class balancing targets (`SAMPLES_PER_CLASS`).
- `A_prepare_data.py`: Merges raw NIH and CheXpert datasets, standardizes resolution, and outputs a master dataset metadata file (`DATA_RAW.csv`).
- `B_preprocess.py`: Processes the raw images, extracts lung ROIs using `unet.py`, applies CLAHE, and outputs ready-to-train images and `DATA_ROI.csv`.
- `unet.py`: The Keras implementation of the U-Net architecture used for lung segmentation.

### 2. Core Model, HPO & Training
- `model.py`: Defines the `VGGSwinHybridNet`. This architecture truncates a VGG16 network to act as an early feature extractor (capturing rich local textures) and bridges it into a Swin-Small Transformer to model long-range global dependencies.
- `HPO_optuna.py`: Runs automated hyperparameter optimization using a Swin-Tiny proxy model to rapidly search for optimal learning rates, mixup alphas, and weight decay values using a persistent SQLite database.
- `G_plot_hpo.py`: Generates interactive HTML visualizations mapping the Optuna optimization history and hyperparameter importances.
- `C_train.py`: The core PyTorch training loop. Handles strict Train/Val/Test splits while ensuring zero patient leakage. Dynamically balances the training set via oversampling/undersampling.
- `E_visualize.py`: Automatically generates publication-ready training graphs (Loss, Accuracy, Macro F1, MCC) from the logs generated by `C_train.py`.

### 3. Evaluation & Ablation Studies
- `D_test.py`: Evaluates the finalized model on the untouched test set, generating robust metrics including Macro AUC, F1, Matthews Correlation Coefficient (MCC), and Cohen's Kappa.
- `threshold_optimizer.py`: Analyzes the raw predictions outputted by `D_test.py` and applies Youden's J statistic to calculate the absolute optimal classification threshold for each disease, maximizing sensitivity and specificity.
- `baselines/train_vgg16.py`: Standard VGG16 baseline training script for exact apples-to-apples ablation comparison.
- `baselines/train_swin.py`: Standard Swin-Small Transformer baseline.

### 4. Interpretability & UI
- `F_gradcam.py`: Implements `SerialGradCAM`, a specialized hook-based class that generates interpretability heatmaps for both the CNN early-stages and the Transformer late-stages. This allows clinicians to see exactly what both architectures are focusing on.
- `app.py`: A Streamlit web application providing a front-end interface for the pipeline. It features automated ROI extraction, classification inference, and dual Grad-CAM rendering. Includes a "Mock Mode" for testing on hardware without GPU capabilities.
- `scratch_stats.py`: A utility to precisely calculate total parameters and theoretical FLOPs for both the U-Net and the HybridNet for academic reporting.
- `extract_statistics.py`: A utility to analyze raw dataset class distributions.

## 🚀 Setup & Installation

### 1. Environment Setup
It is highly recommended to use a Conda environment:
```bash
conda create -n thesis python=3.10
conda activate thesis
pip install -r requirements.txt
```

### 2. Required Weights
Create a `weights/` directory in the project root. You will need:
- `cxr_reg_weights.best.hdf5`: The pre-trained U-Net weights for lung segmentation.
- `best_model.pth`: The finalized PyTorch weights generated after running `C_train.py`.

## 💻 How to Use

### Step 1: Data Preparation
Place the `raw_nih` and `raw_chexpert` data in the root directory and run:
```bash
python A_prepare_data.py
python B_preprocess.py --download-weights
```

### Step 2: Hyperparameter Optimization (Optional)
If you wish to tune hyperparameters before full training:
```bash
python HPO_optuna.py
python G_plot_hpo.py
```

### Step 3: Full Training
Adjust your desired hyperparameters in `config.py` (such as `NUM_CLASSES` and `SAMPLES_PER_CLASS`), then initiate training:
```bash
python C_train.py --fold 0
python E_visualize.py
```

### Step 4: Evaluation & Thresholding
Calculate metrics on the test split and optimize prediction thresholds:
```bash
python D_test.py --fold 0
python threshold_optimizer.py
```

### Step 5: Launching the App
To demonstrate the pipeline and view the Grad-CAM outputs in an interactive UI:
```bash
streamlit run app.py
```
